# Defect repair — T-081

status: fixed
lease: `application/internal/acceptance/**`, `packages/assembly-sdks/typescript/neuronruntime-sdk-0.1.0.tgz`

## Reproduction
- `./scripts/script.sh` from repo root — before fix: four acceptance tests failed (`TestR5_24_DuplicateSignalDeliveryCausesOneResume`, `TestR5_25_SignalDeliveryRejectsUnauthorizedAndWrongExecution`, `TestR5_22_SuspendRestartDeliverSignalResumesWithPayload`, `TestR5_23_R5_13_DurableTimerFiresAfterRestartIncludingMissedDue`) with `main module (github.com/neuron-runtime/neuron/application) does not contain package github.com/neuron-runtime/neuron/application/internal/acceptance/testdata/suspendruntime`; script ended with `FAILED: ./application`.
- Focused pre-fix regression test `cd application && GOWORK=off go test -count=1 -run '^TestSuspendRuntimeFixtureBuildsWithWorkspaceEnabled$' -v ./internal/acceptance` — failed with `build.sh with workspace enabled: exit status 1` plus the same main-module error.

## Root cause
- `application/internal/acceptance/testdata/suspendruntime/build.sh:7` (pre-fix) ran `go build .` with the caller's ambient `GOWORK`, so under `scripts/script.sh` (which runs `go test ./...` inside `go.work`) Go attributed the standalone fixture directory to the `application` main module instead of the fixture's own `go.mod`, and the capability runtime build failed.

## Fix
- `application/internal/acceptance/testdata/suspendruntime/build.sh:11` — `GOWORK=off go build -trimpath -buildvcs=false -o "$out" .` makes the fixture build in its own module regardless of the caller's workspace context; the local `replace` directives stay relative to the fixture source and both invocation styles work. No other behavior changed.

## Regression test
- `application/internal/acceptance/durable_suspend_test.go:162` — `TestSuspendRuntimeFixtureBuildsWithWorkspaceEnabled` runs the installed fixture's `build.sh` with the repository `go.work` explicitly set and asserts the executable is produced. Failed before the fix with the reported error; passed after it.

- `application/internal/acceptance/testdata/blockingruntime/build.sh`, `application/internal/acceptance/testdata/workerdeadline/build.sh` — no: those fixtures copy their standalone `go.mod` into the temporary project and build there, outside the workspace modules; the full script passes them.

## Risks and limitations
- `GOWORK=off` is now unconditional for this fixture; that is correct because the fixture is deliberately an independent module, but it overrides any future attempt to build it through a workspace.
- The new regression test takes ~65s on a cold Go build cache; acceptable for the acceptance package, whose full suite already takes minutes.

## Discovered but not fixed
