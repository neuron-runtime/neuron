## Implemented

- `WithWaitStore` durable-mode option, `WaitStore` boundary, and validated `TimerPollConfig` with Phase 5 defaults (1s interval, 256 batch, 30s lease).
- Scheduler `EnterWait`: commits wait entry with timer effects when `WaitUntil` is present; no timer for signal waits without a deadline; restores the pre-wait snapshot on commit failure.
- Scheduler `ResolveSignal`: pre-checks delivery idempotency, commits state + delivery + timer cleanup + dispatch intent atomically, reloads durable state on replay, and publishes `CapabilityReady` only after commit.
- `DispatchPublishError`: distinguishes committed-but-unpublished dispatch work so a reconciler can republish it.
- `PollDueTimers`: callable bounded batch, due-time discovery, fresh 32-byte crypto-random owner token per claim, lease renewal, timer/deadline policy expiry, fenced timer deletion in the same transaction, and post-commit publication.
- `ExecutionStore.Reload`, `GetSignalDelivery`, and `DueWaitTimers` read helpers.
- Resume payload is stored in execution params as well as wait delivery metadata so a resumed capability receives the delivered payload as input.

## Review and remaining risks

- Independent reviewer approval is pending for `059cae7`.
- `T-040` records the confirmed latent recovery defect: a fully `StatusWaiting` execution is skipped by `Scheduler.RecoverExecution` and `RecoverableDispatch`. The fix belongs to T-024 recovery work, not this slice.
- The poller currently leaves a claimed timer in place when the execution is terminal, missing, no longer waiting, or its snapshot deadline is still in the future. This defensive cleanup must be handled with the cancellation/failure cleanup slice; it must not be fixed by blindly deleting a timer whose snapshot still needs it.
- If a terminal deadline expiry commits unsuccessfully, the in-memory execution remains terminal while the durable record does not. This follows an existing terminal-transition pattern but needs review before T-024 is closed.
- PostgreSQL parity remains unverified without `NEURON_TEST_POSTGRES_DSN`.
