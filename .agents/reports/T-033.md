## Root cause
- `nore/internal/mechanism/process/worker.go:617-618` — the process worker still used the pre-regeneration protobuf Go field names `AttemptID`/`LogicalOperationID`, while the regenerated `shared/protocol/capabilityruntime/v1/capability_runtime.pb.go` emits `AttemptId`/`LogicalOperationId`; the struct literal therefore referenced nonexistent fields.

## Fix
- `nore/internal/mechanism/process/worker.go:617` — `AttemptID` → `AttemptId`.
- `nore/internal/mechanism/process/worker.go:618` — `LogicalOperationID` → `LogicalOperationId`.
- Only the two field labels changed; values, alignment, and behavior are unchanged.

## Regression test
